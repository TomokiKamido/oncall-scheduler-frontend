🔧 サーバー起動手順

1. ターミナルを開いて以下を実行：
cd /Users/kamidotomoki/Documents/oncall-scheduler/frontend2/oncall-scheduler-frontend
2. Node.jsバージョン確認：
node --version
※ v16以上推奨、v22の場合はOpenSSLオプションが必要
3. 依存関係インストール：
npm install
4. サーバー起動（以下のいずれかを試行）：
npm run start:port
または
PORT=8080 NODE_OPTIONS="--openssl-legacy-provider" npm start
または
npm start

🌐 アクセスURL

サーバー起動後：

http://localhost:3000

http://localhost:8080

🔍 トラブルシューティング

ポート使用確認：

lsof -i :3000

lsof -i :8080

🛠️ 代替方法

ビルド後の配信：

npm run build

npx serve -s build -l 8080

🐍 Python代替

Pythonサーバー：

python3 -m http.server 8080

（publicディレクトリで実行）
