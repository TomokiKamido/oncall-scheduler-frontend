# Oncall Scheduler Frontend

このプロジェクトは、当直割作成ソフトのフロントエンド部分を実装したものです。Reactを使用して構築されており、スケジュール管理やスタッフ管理の機能を提供します。

## 構成

- **public/**: アプリケーションの静的ファイルを格納します。
  - **index.html**: アプリケーションのエントリーポイントとなるHTMLファイルです。
  - **favicon.ico**: アプリケーションのファビコンファイルです。

- **src/**: アプリケーションのソースコードが含まれています。
  - **components/**: 再利用可能なコンポーネントを格納します。
    - **common/**: 共通コンポーネント（ヘッダー、レイアウトなど）。
    - **schedule/**: スケジュール関連のコンポーネント（カレンダー、フォーム、リストなど）。
    - **staff/**: スタッフ関連のコンポーネント（フォーム、リストなど）。
  - **pages/**: 各ページコンポーネントを格納します（ダッシュボード、スケジュール、スタッフ）。
  - **hooks/**: カスタムフックを格納します（スケジュール、スタッフのデータ管理）。
  - **services/**: APIとの通信を管理するサービスファイル。
  - **types/**: 型定義をまとめたファイル。
  - **utils/**: ユーティリティ関数を格納します（例: 日付関連）。
  - **App.tsx**: アプリケーションのメインコンポーネント。
  - **index.tsx**: アプリケーションのエントリーポイント。
  - **index.css**: アプリケーション全体のスタイルを定義するCSSファイル。

- **package.json**: プロジェクトの依存関係やスクリプトを定義するnpmの設定ファイルです。

- **tsconfig.json**: TypeScriptのコンパイラオプションやコンパイル対象のファイルを指定する設定ファイルです。

## インストール

プロジェクトをクローンした後、以下のコマンドを実行して依存関係をインストールします。

```
npm install
```

## 実行

開発サーバーを起動するには、以下のコマンドを実行します。

```
npm start
```

ブラウザで `http://localhost:3000` にアクセスすると、アプリケーションが表示されます。

## 開発ルール

### エージェントモード使用時のルール

AIエージェントに開発依頼をする際は、以下の手順を遵守してください：

1. **依頼内容の解釈と計画提示**
   - エージェントは依頼内容を詳細に分析・解釈
   - 具体的な実施計画と変更内容を明示
   - 影響範囲や注意点を説明

2. **実行許可の確認**
   - ユーザーからの明示的な実行許可が必要
   - 「実行してください」「進めてください」「許可します」等の明確な許可
   - 曖昧な指示では自動実行しない

3. **許可後の実行**
   - 明示的な許可を得た場合のみコード変更等を実施
   - 許可なしでのファイル変更は禁止

このルールにより、意図しない変更や影響を防止し、安全な開発を行います。
